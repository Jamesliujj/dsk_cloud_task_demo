# 星际打飞机 · Neon Shooter

一个零依赖、单页运行的 HTML5 Canvas 纵向打飞机游戏。霓虹街机风格，支持桌面和移动端。

## 运行

```bash
# 任选一种静态服务器
python -m http.server 8080
# 或
npx serve .
```

打开 <http://localhost:8080>。

## 操作

| 操作 | 桌面 | 移动端 |
|---|---|---|
| 移动战机 | 鼠标拖动 / WASD / 方向键 | 触摸拖动 |
| 射击 | 自动射击（空格也可） | 自动射击 |
| 暂停 | `P` / `Esc` | 点击暂停按钮（页面失焦自动暂停） |
| 重开 | `R` / 按钮 | 按钮 |
| 静音 | `M` / 按钮 | 按钮 |

## 玩法

- 击落侦察机、蛇形机和重装坦克；每 5 波出现旗舰。
- 连射、护盾、额外生命三类道具随机掉落。
- 击中后短暂无敌；护盾可抵消一次伤害。
- 最高分保存在 `localStorage`。
- 波次越高，敌人越密、速度越快。

## 文件

- `index.html` — 页面、HUD、菜单/暂停/结算界面
- `styles.css` — 霓虹视觉、响应式布局
- `game.js` — Canvas 游戏循环、实体、碰撞、粒子、WebAudio 音效

无外部图片、字体、音频或网络请求。
